Choose your exports

Select the CSV you plan to import. Add an earlier export to compare them.

02

Set validation rules

Use stable keys, such as a SKU, to match rows across exports. Combine columns when a single column is not unique. Column names are case-sensitive.

This filters changed values only. Added and removed rows, schema mismatches, and all validation checks are still reported. “Unchanged” means unchanged within the selected scope.

Advanced rules Types, limits, allowed values, and rule files

Set per-column rules as JSON. Supported types: string, number, integer, and date (YYYY-MM-DD). Use min and max for numeric columns and enum for allowed text values.

Example: {"Quantity":{"type":"integer","min":0},"State":{"type":"string","enum":["active","archived"]}}

The source files are never modified.
